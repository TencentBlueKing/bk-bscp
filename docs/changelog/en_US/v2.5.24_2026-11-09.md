# v2.5.24 Release Notes
### Features
- [Project and Environment] Configs can be isolated by project and environment, covering development, testing, staging, and production
- [Multi-tenant] Supports tenant isolation for configs, clients, users, and approvals
- [Service Management] The service list supports table view and custom columns, and a service can be cloned together with its configs and scripts
- [Service Management] File configs support content encoding, unpublished changes support diff, and batch restore is supported
- [Group Management] Label selection supports IP suggestions, and canary release keeps a stable match for the same client
- [Variable Management] Variable values support multiline text, and template variables support batch import from JSON and YAML
- [Configuration Template] Configuration templates support packaged download
- [Service Key] Supports certificate chains and RSA private keys, and checks for expired certificates before release
- [Approval and Audit] Added release approval and operation records, and the version list shows pending-approval status
