# v2.5.24 版本更新日志
### 新增
- 【项目与环境】支持按项目、环境隔离配置，覆盖开发、测试、预发布、生产
- 【多租户】支持多租户隔离，配置、客户端、人员与审批按租户区分
- 【服务管理】服务列表支持表格展示与自定义列，支持克隆服务并关联配置和脚本
- 【服务管理】文件型配置支持内容编码，未上线配置支持修改对比，支持批量恢复
- 【分组管理】标签选择支持 IP 联想，灰度支持按客户端稳定命中
- 【变量管理】变量值支持多行文本，模板变量支持 JSON、YAML 批量导入
- 【配置模板】配置模板支持打包下载
- 【服务密钥】支持链式证书与 RSA 私钥，上线前校验过期证书
- 【审批与操作记录】新增版本上线审批与操作记录，版本列表展示待审批状态
